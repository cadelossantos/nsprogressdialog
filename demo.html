NS Progress Dialog — Record Panes simulator

Runs the real nsprogressdialog.js in the browser with a mocked N/https. Record panes append mid-process and at completion; clicking a pane opens the record URL.

Auto (Suitelet poll) mode

Mock suitelet returns a timed sequence: PROCESSING (panes appended over steps) then COMPLETE with the full list. The failure variant ends FAILED and shows the red error box.

Manual (controller) mode

Controller is driven with update({processed,total,panes}) and addPanes(); the success variant ends with complete(), the failure variant with fail({ errorMsg }) to show the red error box.

Streaming (load per pane)

Streams one pane per tick up to 200 (animated cascade, count +1 each), then fills to Count: 2000 and flips to the virtualized windowed list.

Virtualized list (2000 rows)

Pane count exceeds MAX_ANIMATED (200) - the list renders virtualized: only ~6 rows exist in the DOM with top/bottom spacers; scroll through all 2,000.
